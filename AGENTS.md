# ATLAS — maintenance

Le dépôt autorisé est `GodSaucisse/atlas`, sur la branche principale `main`.

Après chaque modification demandée par Mathis : effectuer les contrôles adaptés, enregistrer le code mis à jour, puis le pousser sur `main`. Utiliser le plugin GitHub pour vérifier le résultat. Intégrer les changements distants éventuels et ne pas forcer l’historique.

Le dépôt étant public, exclure les secrets, les paramètres privés de l’hébergement, les fichiers locaux d’environnement, les données de joueurs, les bases locales, les dépendances installées et les sorties de compilation. Conserver ces éléments dans leur environnement d’origine. La synchronisation du code ne modifie pas les comptes ni les progressions du jeu.
